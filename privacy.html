4. 국외 처리·이전

Google Gemini API 요청 시 답변 생성에 필요한 메시지·대화 문맥이 암호화된 네트워크로 Google에 전송됩니다. Google Analytics는 선택 분석 동의 후 브라우저에서 Google로 방문·기기·이벤트 정보를 전송합니다. Google은 미국을 포함하여 Google 또는 처리업체가 시설을 운영하는 국가에서 정보를 처리할 수 있으며 특정 단일 국가에 처리가 고정되어 있지 않습니다.

이전받는 자: Google 및 해당 서비스 처리업체. 목적: AI 답변 제공·콘텐츠 안전 검사 또는 동의한 이용 통계. 시점·방법: 대화 요청 시 또는 분석 이벤트 발생 시 HTTPS 전송. 보유·이용: 각 서비스 약관·개인정보 정책의 서비스 제공·안전성 유지·법적 의무 이행에 필요한 기간에 따릅니다. Google의 API 요금제에 따른 입력·출력 처리 기준은 Gemini API 약관, 처리 지역·연락처 등은 Google 개인정보처리방침에서 확인할 수 있습니다.

AI 응답 제공에 필요한 국외 처리는 서비스 계약 이행을 위한 처리에 관한 법적 요건에 따라 안내하며, 별도 동의가 필요한 처리는 해당 절차를 적용합니다. 처리를 원하지 않으면 메시지를 전송하지 않고 고객센터에 처리 중단·삭제·탈퇴를 요청할 수 있으나 AI 대화 제공은 제한됩니다. 분석 관련 국외 전송은 ‘쿠키 설정’에서 거부·철회할 수 있습니다. 민감하거나 타인을 식별하는 정보를 대화에 입력하지 마세요.

5. 쿠키와 브라우저 저장소

브라우저 알림은 이용자가 직접 허용한 경우에만 구독합니다. 알림 수신에 필요한 브라우저 푸시 주소, 암호화용 공개키, 내부 계정 연결과 수신 설정을 보관하며, 설정에서 알림을 끄거나 로그아웃하면 해당 기기 구독을 해제합니다. 새 메시지 알림은 Google·Apple·Mozilla 등 이용 브라우저의 푸시 서비스를 통해 전달되며 알림 전송 데이터에는 대화 본문이나 전화번호를 포함하지 않습니다. 먼저 오는 연락은 기존 대화 문맥을 바탕으로 AI가 생성하며 설정에서 중단할 수 있습니다.

계정 복원용 보안 쿠키는 최대 1년간 유지되며 HttpOnly·Secure 속성으로 관리합니다. 로컬 저장소에는 세션·대화 화면 상태·쿠키 동의 설정 등이 저장됩니다. 브라우저 설정으로 쿠키·저장소를 삭제하거나 차단할 수 있지만 게스트 복원과 일부 기능이 제한될 수 있습니다.

분석 쿠키는 별도 허용 후에만 사용하며 Google Signals·광고 개인 최적화는 사용하지 않습니다. 대화 홈의 ‘쿠키 설정’에서 선택을 변경할 수 있고, Do Not Track 요청이 감지되면 분석 태그를 불러오지 않습니다. 이 안내 페이지와 관리자·고객센터에는 분석 태그를 삽입하지 않습니다.

6. 보관·파기와 운영자 접근

계약·청약철회 및 대금결제·공급 기록은 5년, 소비자 불만·분쟁 기록은 3년, 표시·광고 기록은 6개월 등 관계 법령이 요구하는 자료는 해당 범위와 기간에 한해 보관합니다. 보관 의무가 없는 정보는 처리 목적 달성 또는 적법한 삭제 요청 확인 후 지체 없이 파기합니다. 전자 자료는 복구할 수 없도록 삭제하고 출력물이 있으면 파쇄 등으로 폐기합니다.

대화방을 목록에서 나가거나 화면에서 지워도 상담·운영 기록은 남을 수 있습니다. 완전 삭제·탈퇴는 고객센터로 요청하세요. 하트의 2년 이용기간은 개인정보 전체의 일괄 삭제기한이 아닙니다. 운영 백업은 최대 14일 순환 보관하며 삭제 후 백업 복원 시 삭제 요청이 다시 반영되도록 확인합니다.

인증된 운영자는 고객 문의 해결·부정 이용 확인·대화 품질 개선을 위해 계정별 대화와 이용 내역에 접근할 수 있고, 관리자 대화 조회와 잔액 변경은 감사 기록에 남깁니다. 고객 간 대화 공개·외부 광고 판매를 위한 열람 목적은 아닙니다. 접근 권한 제한, HTTPS, 인증번호 해시, 인증 시도 제한, 비밀키의 서버 보관 등 보호 조치를 적용합니다.
