# 오래 지난 뒤의 선연락 — 2026-10-21

- 선연락 성향이 있는 소수 캐릭터(기존 약 5%)에 적용한다. 정상 사용자 메시지가 4개 이상 있는 대화만 대상으로 삼는다.
- 캐릭터별로 2~5일 / 6~14일 / 15~45일 / 46~90일 / 91~180일 중 한 범위를 안정적으로 배정한다. 실제 날짜는 캐릭터·계정·마지막 사용자 턴에 따라 그 범위 안에서 달라진다.
- 마지막 사용자 메시지 시각을 기준으로 한 번 예약한다. 앱 실행·재입장·읽음·배포 재시작으로 날짜를 미루거나 재예약하지 않는다. 짧은 무응답 리마인드도 장기 예약을 취소하지 않는다.
- 장기 연락을 보낸 뒤 응답이 없으면 다시 예약하지 않는다. 새 사용자 대화가 완료되어야 다음 주기가 시작된다. 생성 실패는 최대 3번 재시도하며 모델이 연락하지 않겠다고 판단하면 그 주기를 생략한다.
- 기존 6~18시간짜리 미발송 예약만 실제 마지막 사용자 턴 기준으로 다시 계산한다. 완료·생략·실패 주기와 대화 이력은 보존한다. 배포 때문에 몇 개월 후로 시각을 초기화하지 않는다.
- 서버가 실제 경과 일수와 지난 대화·기억을 LLM에 전달한다. 과거의 특정 이야기나 관심사가 문득 생각나서 연락하는 분위기로 생성하되 같은 도입부를 강제하지 않는다. 현재 생활·건강·감정을 관찰했다고 꾸미거나 오래전 일정이 아직 예정된 일처럼 말하지 않도록 지시한다.
- 하트 차감 없음. 고정 문구 없음. 새 사용자 발화를 꾸며 저장하지 않음. 불필요한 연락은 모델 판단으로 생략한다.
- 한국 시간 10~22시에만 발송하고, 최근 10분 접속자는 미루며, 계정 전체 장기 연락은 최소 3일 간격을 유지한다. 알림 권한과 선연락 설정을 존중하고 푸시에는 대화 원문을 넣지 않는다.
