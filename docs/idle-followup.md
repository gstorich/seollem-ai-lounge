# 무응답 리마인드 — 2026-10-21

- 캐릭터의 답변 뒤 45~75초간 사용자 답장이 없을 때 시도한다.
- 캐릭터별 마지막 정상 사용자 메시지를 기준으로 최대 2회다. 방 재입장, 새로고침, 읽음 처리는 초기화 조건이 아니다.
- 횟수는 서버 대화 기록에서 계산하며 기존 `idle_followup_` 메시지도 포함한다. 새 정상 사용자 메시지 뒤에만 새 한도가 시작된다.
- 프런트의 고정 문구 풀을 제거했다. 서버의 인증·동의·선연락 설정 확인과 생성 잠금을 거쳐 실제 LLM으로 생성하고, 기존 캐릭터·대화 기억·성인 접근 정책을 적용한다.
- 하트는 차감하지 않고 가짜 사용자 발화를 기록하지 않는다. API 실패 시 대사를 대체하지 않고 기존 중앙 오류 안내를 사용한다.
- 새 답장·방 이동·생성 경합 등으로 문맥이 달라지면 지난 리마인드는 취소한다. 모델이 보낼 내용이 없다고 판단하면 캐릭터를 퇴장시키지 않고 해당 사용자 턴의 시도를 중단한다.
- 장시간 부재에 대한 희귀 서버 선연락(일부 캐릭터, 캐릭터별 2~180일 대기, 3일 전역 간격)과는 별도 기능이다.
