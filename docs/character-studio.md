# 캐릭터 스튜디오 운영

어드민의 **캐릭터 스튜디오**에서 새 인물을 만들거나 기존 인물을 편집·복제합니다.

1. 이름, 성인 나이, 공개 소개와 프로필 이미지를 정합니다. 이미지는 제공된 라이브러리에서 선택합니다.
2. 성격과 반응, 배경, 원하는 것, 결점, 취향, 말투, 상황별 반응과 첫 대화 방향을 작성합니다. 예시 대화는 최대 8개입니다.
3. **초안 저장 후 새 대화 테스트**로 실제 AI가 만드는 첫마디와 후속 대화를 확인합니다. 변경한 설정은 저장 후 새 테스트로 확인합니다.
4. **저장하고 공개**하면 새 매칭에 즉시 반영됩니다. 초안만 저장하면 운영 중인 공개본은 유지됩니다.
5. **공개 중지**하면 새 매칭과 선제 연락에서 제외됩니다. 이미 시작한 고객 대화는 유지됩니다.

직접 작성한 설정은 자동 성향·말투 조합을 대신합니다. 배경은 인물 자신의 사실로, 예시 대화는 말투 참고로 구분하며 사용자의 과거나 실제 대화로 기억하지 않습니다. 첫 대화 지침은 첫마디 생성에만 사용합니다. 매 턴 공개된 설정, 관계와 대화 기억을 함께 전달합니다. 모델이 언제나 모든 지침을 완벽하게 따르는 것은 아니므로 취향 충돌·갈등·호칭·장기 맥락을 테스트한 뒤 공개하세요.

설정 원문은 관리자 API에서만 전달하며 고객용 프로필 응답에는 넣지 않습니다. 단, 캐릭터가 대화에서 자신의 배경이나 취향을 말할 수 있으므로 설정에 비밀키·실제 개인정보를 넣지 마세요.

초안과 공개본은 SQLite에 분리 저장되며 서버 재시작과 배포 뒤에도 유지됩니다. 수정 충돌은 버전 검사로 차단합니다. 생성·저장·공개·중지는 관리자 처리 기록에 남깁니다. 테스트는 고객 계정·하트·채팅과 분리되며 세션은 2시간 후 만료됩니다. 만료된 테스트 데이터는 다음 테스트 요청 때 정리합니다. 테스트는 하트를 차감하지 않지만 실제 AI API 사용료가 발생합니다.

검증: `node server/tests/character-studio.cjs`는 임시 DB와 모의 제공자로 권한·공개·설정 전달·테스트 격리를 확인합니다. 실제 제공자 검증은 운영 DB를 사용하지 않는 `node server/scripts/evaluate-authored-characters.cjs --live`로 실행합니다. 이 명령은 실제 API 비용을 발생시키므로 배포 자동 검사에는 포함하지 않습니다.
