# 아지트챗 정책 보강·운영 확인 (2026-10-19)

## 반영 내용

- 정책 2.0과 서버 수락 버전 `2026-10-19.2`: 이용약관, 개인정보, 환불, 이용·청소년 보호, 정책·변경 이력, 보강 전 보관본.
- 실제 사업장 3층, 사업자정보 확인 경로, 게스트/비로그인 고객의 이메일·전화 권리 행사 경로.
- 현재 Gemini API의 만18세 이상 조건과 별도 만19세 이상 확인을 구분. 기본 미동의, 별도 체크, 서버 기록, 알려진18세 미만 차단.
- 7일 이내 전량 미사용 일반 환불 유지. 법정 기산일·미제공·미성년 계약 취소·가분적 콘텐츠 등 법정 권리 예외 보존. 과거 구매 권리 소급 축소 금지.
- 입력·응답·기억·안전 검사, 운영자 접근·감사, 국외 처리, 유료 API의55일 안전 보관 안내. 사용자 확인으로 유료 결제 계정 연결 사실 확인(자동 계정 감사 아님).
- 선택 분석/알림을 필수 이용 동의와 구분. 쿠키 철회 삭제,180일 만료, 접속 로그 쿼리/리퍼러 제외 및30일 순환, 기존14일 백업.
- 임의 변동 접속자 수를 실제 미매칭 캐릭터 수로 바꾸고 AI 표시. 대화방 나가기와 원문 완전 삭제의 차이 안내.

## 개통·운영 전에 별도로 확인할 사항

1. 다날은 신청 접수·계약 진행 중이다. 승인·비용·실제 인증 항목·보관 기준·이전/위탁 관계를 확정하고 실제 PC/모바일 인증을 검증한 뒤 활성화한다. 테스트 결과를 실제 성인인증으로 사용하지 않는다.
2. 현재 결제 어댑터는 Danal 카드 경로다. 토스페이·카카오페이 신청 승인은 어댑터 구현·개통·실결제 테스트와 별개다. 현재 두 기능 모두 비활성 유지. 승인 업체명·수단을 고지한 뒤 실제 제공 상태에 맞춘다.
3. Google 계약/DPA·실제 재위탁 업체 및 처리 국가 목록을 확보하고 국외 이전 안내의 구체성·법적 근거를 최종 확인한다. 전 세계 처리를 단일 국내 국가로 허위 표시하거나 방침만으로 별도 동의 요건을 면제하지 않는다. 이 공개 문서는 현 공급자 문서가 설명하는 분산 처리를 밝히지만 최종 국가 목록 확인을 대체하지 않는다.
4. GA4 실제 속성의 사용자·이벤트 보관 기간(2/14개월)을 확인하고 단일 실제 기간으로 공개 안내를 확정한다. 브라우저 쿠키180일 설정과 서버 측 보관 설정은 다르다. 광고/Signals 비활성 상태를 유지한다.
5. 개인정보 삭제·탈퇴 요청은 주문·분쟁 법정 보존을 구분해 처리한다. 계정·대화 원문/기억·아카이브·별칭·푸시·인증·수락 증빙의 대상과 근거를 확인하고 삭제 작업 및 백업 복원 재반영을 기록한다. 사용자에게 처리 완료를 통지하고 불가 범위의 법적 근거와 기간을 안내한다. 단순 대화방 나가기를 원문 파기 완료로 통지하지 않는다.
6. 캐릭터 이미지·폰트·소스의 상업적 이용 권리와 실존인물 권리, 개인 정보 처리 위탁/DPA 체결 여부를 증빙으로 확인한다. 약관으로 없는 사용 권리를 새로 만들 수 없다.
7. 생체정보·정치적 견해·건강·실제 성생활 등 민감정보는 일반 약관 수락으로 처리 동의를 간주하지 않는다. 별도 기능 도입 시 필요성·독립 동의와 보호를 검토한다.
8. 운영자 접근 목적·필요성, 법정 보존/파기 절차, 국외 이전, 이용 제한·성인 콘텐츠 범위는 실제 계약과 운영 증빙을 갖춰 국내 법률 전문가의 검토를 받는다. 이 작업은 법률 적합성 인증이나 PG 승인 보장이 아니다.
