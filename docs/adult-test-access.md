# 운영자 QA용 임시 성인 기능 접근

실제 인증기관 완료 기록(`identityVerification`)을 생성하거나 위조하지 않는다. 서버 전용 `adult_test_access`에 운영자가 발급한 권한이 있고 휴대폰·계정이 일치하는 테스트 계정만 최대 24시간 기능 접근을 테스트한다. 확인된 미성년자에게는 적용되지 않는다. 클라이언트/API로 권한을 발급하는 기능은 제공하지 않는다.

본인인증 상태 응답은 `verified: false`를 유지하며 별도 `testAccess`와 만료 시각을 반환한다. 기존 유효한 기관 인증이 있으면 그 기록은 그대로 보존한다. 결제·본인확인 화면과 관리자 상세에는 '기관 인증 아님'을 표시하고 안전 모니터링은 `adult_test`로 분리한다. 실제 인증 성공 이벤트는 생성하지 않는다. 임시 권한의 만료는 매 요청 시 서버 시각으로 판정하며, 기존 관리자 인증 해제 기능으로 즉시 회수할 수 있다.

발급은 사용자에게 명시적으로 요청받은 계정에만 수행하고 `adult_test_granted` 감사 기록에 대상·발급 시각·만료 시각을 남긴다. 서비스 전체 보호 정책이나 인증기관 설정은 변경하지 않는다. 만료 후에는 정상 본인인증 절차가 필요하다.

검증: `node server/tests/adult-test-access.cjs` (운영 모드 거부 및 격리된 테스트 모드, 테스트 계정/휴대폰 결합, 24시간 만료, 미래 시각·과도한 만료 거부, 다른 계정 거부, 미성년자 거부, 기관 인증과 분리, 권한 회수).
