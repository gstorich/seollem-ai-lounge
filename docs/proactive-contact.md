# 먼저 오는 연락과 브라우저 알림

## 동작

- 캐릭터 ID를 기준으로 고정된 약 5%에만 먼저 연락하는 성향을 부여한다. 성별과 무관하다.
- 기존 방에서 사용자 메시지가 4개 이상이고 실제 API 답변까지 완료된 경우 예약한다. 마지막 답변으로부터 6~18시간 후가 최초 후보 시간이다.
- 한국 시각 10~22시에만 생성·푸시 전송한다. 사용자가 사이트를 보고 있으면 최소 10분간 보류한다.
- 계정 전체에서 최소 72시간 간격이다. 마지막 사용자 메시지가 7일보다 오래되면 보내지 않는다. 연락 후 사용자가 답하지 않으면 같은 방에서 연속으로 보내지 않는다.
- 기존 방은 최근 7일 내 서버 대화 상태가 있는 방을 점진적으로 예약한다. 배포 시 과거 연락을 몰아서 보내지 않는다.
- 모델이 기존 감정, 기억, 말높임과 원문 시각을 함께 참고해 실제 API로 생성한다. 연락이 부적절하면 `roomLeft:true`로 발송을 생략한다. 생성 실패 시 고정 대사를 보내지 않는다.
- 먼저 온 메시지는 하트 잔액과 관계없이 무료다. 사용자의 후속 답장은 기존 과금 규칙을 따른다.

## 저장과 경쟁 상태

`proactive_jobs`는 SQLite에 예약·상태·재시도·생성 임대를 보존한다. 사용자 단위 생성 잠금을 일반 대화와 공유하며, 완료 직전에 현재 방, 마지막 메시지, 수신 설정, 접속 시각과 기억 revision을 다시 확인한다. 메시지·기억·읽지 않음·전송 대기열이 같은 트랜잭션으로 저장된다. 생성 요청을 사용자 발화로 저장하거나 하트를 차감하지 않는다.

방 삭제 시 예약을 취소한다. 수신 설정 해제 시 생성 중이던 결과도 버린다. 번호 연결 시 기기 구독과 설정을 계정으로 이동하고 예약을 다시 평가한다. 실패한 생성은 6시간 뒤 최대 총 3회 시도한다. 예약 작업은 서버 재시작 뒤에도 이어진다.

## 알림과 사용자 제어

설정 · 계정에 ‘가끔 먼저 오는 연락 받기’와 ‘브라우저 알림 허용’을 제공한다. 연락은 목록에서 받을 수 있으며 OS 알림 구독은 별도 선택이다. 브라우저 권한 요청은 명시적인 버튼 클릭 안에서만 실행한다. 알림 끄기는 현재 브라우저 구독을 해제하고, 로그아웃 시에도 해제한다. 다른 기기는 각자 설정한다.

푸시 본문은 ‘대화 상대에게 새 메시지가 왔어요’이며, 실제 대화·전화번호·세션 토큰은 넣지 않는다. 알림 클릭 시 로그인된 계정에 존재하는 방만 연다. 서비스 워커는 캐시·API 토큰을 보관하지 않는다. 푸시 주소는 주요 브라우저 제공자의 HTTPS 호스트만 허용해 임의 서버 접근을 막는다. 만료된 구독(404/410)은 삭제하고, 일시 실패 시 이미 전달한 기기를 제외하고 최대 3회 재시도한다. 전송 후 기록 전 프로세스 중단 등에서는 중복 전송 가능성이 있어 고정 알림 tag로 중복 표시를 줄인다. 브라우저·OS 설정이나 네트워크 상태에 따라 실제 알림 전달은 지연될 수 있다.

VAPID 키는 배포 시 최초 1회 서버 환경 파일에 생성하며 코드·클라이언트·로그에 비밀키를 넣지 않는다. 키를 재생성하면 기존 구독을 재등록해야 하므로 릴리스마다 회전하지 않는다. 구독을 확인하기 위한 테스트는 합성 데이터만 사용한다.

관련 표준: [MDN 알림 권한과 사용자 제스처](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API/Using_the_Notifications_API), [Apple Web Push](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers). iOS/iPadOS는 홈 화면에 추가한 웹앱에서 알림을 허용해야 한다.

## 검증

`node server/tests/proactive.cjs`: 희소성, 야간 제한, 접속·계정 간격, 무료 생성·기억 동시 저장, 오류·설정 해제·방 삭제, 합성 입력 근거 제외, 푸시 주소 검증, 만료 구독·기기별 재시도·번호 통합.

`node server/tests/notifications.cjs`: 인증·계정 격리·타인 구독 해제 방지, 정적 워커·manifest, 클릭 전 권한 요청 없음, 구독·로그아웃 해제, 일반 알림·방 열기.
