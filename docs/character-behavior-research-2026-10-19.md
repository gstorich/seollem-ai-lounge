# 캐릭터의 태도와 첫 대화 개편

## 조사 범위

2026-10-19에 공개적으로 접근 가능한 제작 문서와 실제 공개 캐릭터의 소개·인트로를 확인했다. 타 서비스에 로그인해 비공개 대화를 실행하거나 내부 모델·프롬프트를 확인한 조사는 아니다. 공개 사례의 문장과 인물 설정을 우리 캐릭터에 복제하지 않았다.

이 조사에서 알 수 없는 것: 타 서비스의 전체 응답 품질, 사용자별 모델·안전 설정, 실제 시스템 프롬프트, 캐릭터별 응답 생성 성공률. 공개 문서가 제안하는 설계와 우리 모델에서의 효과는 별개이므로 실제 API로 별도 검증한다.

## 확인한 원인

기존 서버 프롬프트는 세부 `speechStyle`, 행동 동기·가이드의 일부를 쓰지 않았다. 전체 캐릭터에게 초면 해요체·두세 마디·부드러운 대응을 공통 적용했고, 남성 캐릭터도 넓은 성격 분류에 따라 비슷한 제한을 받았다. 개별 타이핑 조합은 달라도 무엇을 말하고 왜 반응하는지가 비슷했다.

첫 시도에서는 성향을 추가해도 기존의 부드러운 프로필·출력 직전의 공통 지침·기억 요약이 반응을 다시 평준화했다. 실제 생성 결과에서 첫 인사의 근황 보고, 민초에 대한 일괄 반대, 사용자가 말높임 변경을 요청했을 때 사무적인 장문 사과로 변하는 현상을 확인해 우선순위를 다시 조정했다.

## 구현

- `characterBehavior.js`: 캐릭터 ID에 고정되는 구체적 성향. 건조함·까칠한 장난·직진 플러팅·무심함·엉뚱함·승부욕·솔직함·낯가림·현실성·경계심을 성격 배경과 조합한다. 이는 편집 설계 비율이며 실제 남녀의 성격 통계가 아니다.
- 인물마다 대화에서 원하는 것, 결점, 자존심·관심의 충돌, 평소 길이·리듬, 취향과 주제별 의견을 결합한다. 대화 중 이미 확인된 인물 사실이 기본값보다 우선한다. 동일 성격·성별 안에서도 다른 성향이 존재한다.
- 첫마디는 인물별 여러 접근 방식 중 하나를 서버 요청 ID로 정한다. 이름·직업·오늘 하루를 묻는 같은 진행 순서를 요구하지 않는다. 고정 인사문을 반환하는 코드는 없다.
- 공통 말높임 기본값을 없애고 인물마다 편한 존댓말·반말·느슨한 혼합형을 사용한다. 사용자가 명시적으로 요청한 말높임·호칭·표현 제한은 항상 우선한다. 모르는 사용자 나이·성별·외모나 이전 관계를 창작하지 않는다.
- 요청 준수와 성격 초기화를 분리한다. 존댓말을 요청하면 존댓말로 이어가고, 설정을 복창하는 장문 사과로 바꾸지 않는다.
- 실제 답장인 `reply`를 먼저 생성하고, 별도 API 호출에서 그 결과에 대한 기억 변경분만 기록한다. 대사 작성 모델에는 기억 추출 지침을 보내지 않고 기록 모델은 대사를 다시 쓸 수 없다. 원문·기억의 근거 검증과 원자적 과금은 유지한다.
- 확인되지 않은 호칭·상투적인 설정 복창·평준화된 첫마디를 발견하면 제공자에게 한 번만 교정 요청한다. 글자 수 때문에 다시 생성하거나 로컬 문구로 고치지 않는다. 잘못된 호칭이 지속되거나 기억 추출이 실패하면 메시지·기억·하트를 저장하지 않는다.
- 과감한 로맨스는 능청스러운 호감·은근한 긴장감으로 드러낸다. 노골적인 성행위 묘사, 거절 후 압박, 사용자 신상 조작을 개성으로 삼지 않는다. AI 여부를 물으면 사실대로 답한다.

## 검증 방법

`server/tests/character-behavior.cjs`는 신원별 안정성·재시작·성격/성별 내 다양성·원래 설정의 통합·첫마디 변화·명시적 말높임의 우선순위를 확인한다. 기존 대화 기억·호칭·과금·오류·선물·먼저 연락하기 테스트도 실행한다.

`node server/scripts/evaluate-character-voices.cjs --live`는 10가지 성향 × 남녀 각 1명, 총 20명의 합성 대화를 실제 제공자로 생성한다. 고객 계정·DB·하트를 사용하지 않는다. 첫마디 → 심심해서 들어온 상황 → 취향 질문 → 자기 의견 재확인 → 장난 중단·존댓말·웃음 제거 요청을 순서대로 검사한다. 동일 입력의 비교는 차이를 발견하는 도구이며 '인간 같음'을 보장하는 통계 점수로 해석하지 않는다.

API 호출 수는 대사 작성과 기억 정리의 두 번이며 교정 시 한 번 더 호출한다. Gemini 3.1 Flash-Lite와 전체 생성 제한 시간 45초, 호출별 출력 한도 16,384토큰을 유지한다. 기본 차감은 3.7하트이며 먼저 온 연락과 첫 인사는 기존 무료 규칙을 유지한다. 응답 지연과 운영 API 비용은 증가할 수 있다.
