# 안부 기록과 접근성 기반 — 2026-10-21

## 이번에 제공하는 기능
- 기존 서버 대화 기억을 이용한 생활 후속 질문: 날짜·현재 화제·이전 질문을 참고하며 매 턴 안부 설문을 하거나 건강 상태를 추정하지 않는다.
- 본인 작성 안부 기록: 날짜, 선택적 기분, 메모. 대화의 본인 메시지에서 초안을 가져올 수 있으나 저장은 직접 확인한다.
- 기본은 본인 전용. 특정 캐릭터를 고르고 참고 허용에 체크한 기록만 그 캐릭터의 생성에 전달한다. 캐릭터별 최신 8개만 참고한다. 기록은 언제든 수정·삭제하며 참고 허가를 철회할 수 있다.
- 저장 기록의 수정 버전 충돌을 검증하고, 생성 도중 참고 범위가 바뀌면 응답 저장·하트 차감을 함께 취소한다.
- 기록을 기존 대화 기억에 복사하지 않도록 생성 지침을 준다. 삭제가 기존 대화 원문까지 지우는 것은 아님을 화면에 안내한다.
- 글씨 3단계, 읽기 속도 3단계, AI 텍스트 합성 읽기. 자동 재생하지 않으며 음성 선물 해금과 독립적인 접근성 기능이다.
- 지원 브라우저의 음성 입력: 음성 처리 안내 확인 + 브라우저 권한. 전송은 항상 본인이 한다. 미지원이면 키보드 마이크로 입력 가능하다.
- 안부 원문을 광고 분석·푸시 알림에 보내지 않는다. 서버는 음성 원본을 수집하지 않는다.

## 가족 공유는 미구현·비활성
현재 보호자 연결, 가족 알림, 대화 자동 요약 전송은 제공하지 않는다. `sharingScope=self`, `source=user`, `schemaVersion=1`은 기록의 출처와 공개 범위를 명시하기 위한 것으로, 가족 공유 동의로 취급하지 않는다.

추후 별도 보호자 연결 확인·이용자 철회·공유 항목과 기간 동의를 갖춘다. 원문이 아닌 '최근 대화 응답 여부·시각' 같은 최소 항목부터 검증한다. '건강하다/걱정하지 않아도 된다'를 AI 대화 여부만으로 단정하지 않는다. 응답이 없다는 사실도 응급 상황으로 단정하지 않는다. 성인·사적 대화 원문, 상대 이름, 성적 취향은 가족 요약에 넣지 않는다. 인증된 별도 수신자 권한과 전송 이력·철회 처리 검증을 갖추기 전에는 공유 엔드포인트를 만들지 않는다.

## 운영 및 한계
- 게스트도 사용할 수 있으나 번호 연결 전 기기·세션 복원 한계가 있다. 번호 연결 시 기존 계정으로 기록을 이전한다.
- 일상 메모용이며 건강정보 입력을 요청하지 않는다. 건강정보 처리 확장은 별도 동의·보관·권한 설계를 선행한다.
- 음성 품질과 인식 지원은 브라우저·기기마다 다르다. 브라우저 음성 처리자는 외부 서비스를 사용할 수 있음을 시작 전에 안내한다.
- 실제 질문 품질은 LLM 출력에 좌우된다. 고정 문구나 로컬 대사로 대체하지 않으며 기존 실패 시 미차감 정책을 유지한다.
