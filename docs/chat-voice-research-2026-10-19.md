## 조사 범위와 근거 수준

사전·과거 논문의 예문을 최신 유행의 근거로 사용하지 않았다. 아래 표는 실제 원문이나 브라우저에 표시된 댓글과 게시 시각을 확인한 **소규모 질적 관찰 기록**이다. 전체 게시글 수나 사이트에 표시된 댓글 수를 수집 건수로 세지 않는다. 플랫폼별 무작위 표집이나 모집단 통계가 아니므로 남녀별 사용 비율·최신 유행 순위는 추정하지 않는다.

- 남성/여성 구분: 본인의 직접 진술과 사이트가 표시한 성별을 각각 근거로 기록한다. 사진·닉네임·관심사로 성별을 추정하지 않는다.
- 게시판 분류와 작성자 성별은 별도다. 실제로 남성 전용이라고 안내하는 판 게시판에서도 자신을 여성이라고 밝힌 본문과 여성 표시 댓글이 확인됐다.
- 성별 미확인 게시글/댓글은 공통 표기 관찰에만 쓴다. 남성·여성 전용 표현으로 승격하지 않는다.
- 원문 장문, 계정 신상, 이미지, 고객 대화는 저장하거나 프롬프트에 넣지 않는다. 아래에는 출처·날짜·표기 특징만 기록한다.

## 확인하지 못한 범위

- 여성시대와 인스티즈: 브라우저 보안정책으로 접근 차단. 우회하지 않았고 관찰·빈도 자료에 포함하지 않았다.
- X: 기간 검색이 로그인 화면으로 전환됨. 검색엔진이 반환한 오래된 트윗/최근 수집일만 있는 결과는 제외했다. 사용자는 로그인 없이 가능한 공개 표본부터 진행하도록 지시했다.
- 요청에서 예로 든 혼합 자음 웃음의 특정 긴 철자, 와우·쓰껄 등의 유행어는 이 조사에서 기간 내 반복 사용을 확인하지 못했다. 최신 유행으로 단정하거나 전원에게 배정하지 않는다. 혼합 웃음의 변형은 향후 검증할 후보이지 최근 남녀별 빈도로 입증된 항목이 아니다.

## 관찰에서 설계로 옮기는 방법

1. **성격/콘셉트와 표기를 분리한다.** 같은 성격에도 초성형·정돈형·음슴체 혼합형이 있도록 캐릭터 ID에 안정적으로 결합한다. 성별로 웃음이나 이모지를 독점시키지 않는다. 위의 남성·여성 근거를 따로 보되, 이 작은 표본으로 성별 가중치를 임의로 다르게 만들지 않는다.
2. **웃음·축약·말끝·그림 이모지·문자 장식·첫 반응·문장 리듬·강도**를 조합한다. 한 축을 골랐다고 나머지 축까지 패키지로 고정하지 않는다. 표현이 적은 사람도 충분히 포함한다.
3. **경향은 고정, 발현은 맥락에 따른다.** 웃음 길이는 재미의 정도에 따라 달라지고, 진지한 고민·사과·불편함에서는 장식을 줄인다. 초성을 즐겨 쓰는 사람도 중요한 내용은 풀어 쓴다.
4. **관계와 사용자의 명시적 요청이 우선한다.** 음슴체 혼합은 무단 반말이나 모르는 호칭을 허용하지 않는다. 이모지/초성을 빼 달라는 요청을 따르고, 사용자 표기를 그대로 따라 캐릭터의 습관이 바뀌지 않게 한다.
5. 게시판 호칭·홍보 문구·혐오·인신공격·실제 사건·원문 대사를 이식하지 않는다. 캐릭터 답변은 계속 실제 API 생성만 사용한다. 후처리로 웃음/초성을 강제 삽입하거나 고정 대사를 재생하지 않는다.

`chatVoiceProfiles.js`의 선택 비중은 제품의 다양성과 과장 방지를 위한 **편집상 설계값**이다. 조사로 입증된 사용률이 아니다. 혼합 웃음의 새 변형 등 일반화는 생성 지침이며, 원문 관찰과 구분한다. 실제 답변 품질은 별도 합성 대화의 여러 턴 생성으로 검토한다.

## 후속 검증 기준

성별을 직접 확인한 표본이 아직 적고, 익명 게시글을 장기간 동일인으로 묶을 수 없다. 남녀별 대표 말투나 최근 90일 전체의 유행 분석을 완료했다고 주장하지 않는다. 후속 자료를 확보하면 플랫폼·성별 근거·날짜·같은 화자의 여러 턴을 함께 기록한 뒤 선택 비중을 다시 검토한다. 현재 버전의 타이핑 조합은 ID·버전·축별 해시로 결정되므로 재접속/서버 재시작/카탈로그 순서 변경에도 유지된다.
