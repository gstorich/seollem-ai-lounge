# 결제·본인확인 배포와 활성화

2026-10-19 다날 **신용카드 일반결제·휴대폰 본인인증**을 포트원에서 재신청했다. 두 건 모두 ‘신청 접수 및 계약 진행 중’으로 확인했다. 사이트 기본 구축 항목은 재검사에서 확인 완료였고, 채팅 위험업종 별도 검토 표시가 남았다. 실제 승인·계약 체결·가입비 결제는 수행하지 않았다. 콘솔에 발급된 LIVE 채널은 기존 비즈사주 KG이니시스뿐이었다. 기존 채널과 키는 복사하지 않았다.

## 구현

- `/billing`: 회원의 상품 선택, 구매 조건 확인, 카드 결제창, 결제 내역·재확인·미사용 주문 전액 환불, 본인확인 시작·결과.
- `/payment/complete`, `/verification/complete`: 모바일 리디렉션 복귀. URL 성공 여부를 믿지 않고 서버가 공급자에서 다시 조회한다.
- 다날 카드: 공식 지원인 PortOne V1 SDK/REST. API 토큰은 서버 메모리에서만 보관한다. 본인확인은 V2 SDK/REST.
- 서버 상품표 금액·상품명·통화·결제수단·다날 MID·주문 nonce·거래 ID를 대조한다. 하트 지급·거래 ID 고유 매핑·주문 완료는 같은 SQLite 트랜잭션이다.
- V1 웹훅은 인증 근거가 아니다. 수신 값은 조회 힌트로만 쓰고 포트원 인증 API에서 거래를 재조회한다. 알 수 없는 주문·임의 URL 조회는 수행하지 않는다.
- 웹훅과 별도로 미완료 주문은 24시간 내 재확인, 지급한 주문은 주기적 취소 확인, 결과가 불명확한 환불은 재조회한다. 한 번에 최대 30개 처리하고 검사 시각으로 순환한다.
- 일반 환불은 PG 승인 시각부터 7일 이내이며 해당 주문 지급분이 전량 미사용인 경우에만 전액 허용한다. 일부 사용·기간 경과는 서버에서 거절하며 법정 환급 사유는 고객센터로 별도 접수한다. 공급 지연 등 법정 기산일 예외도 별도 검토한다. 다른 주문·무료 하트를 가져오지 않는다. 환불 요청 시 원래 지급분을 보류해 동시 소비를 막는다.
- 취소 거절과 미취소 상태가 확인되면 원래 지급분·유효기간으로 하트를 복원한다. 통신 실패처럼 취소 결과가 불명확하면 보류를 유지하고 자동 취소 재시도는 하지 않는다. 포트원에서 취소가 확인되면 완료한다. 불명확한 미취소 건은 관리자/PG 확인이 필요하며 보류를 임의 해제하지 않는다.
- 외부 PG 취소가 발생하면 남은 해당 유료 하트를 회수하고, 이미 소비된 금액 등 자동 조정할 수 없는 차이는 ‘확인 필요’로 표시한다. 고객에게 음수 하트를 자동 부과하지 않는다.
- 어드민 `결제·환불`: 주문·고객·금액·취소·미사용분·확인 필요·재조회·환불 요청과 작업 감사 기록. 통계는 서버에서 확인된 주문 기준.
- 본인확인: 서버 발급 ID를 계정에 묶고, 상점 지정 API 조회·채널 키/모드/다날 제공자·VERIFIED·동일 전화번호·유효한 생년월일을 검증한다. 확인 여부·만 19세 여부·확인 시각만 사용자에 저장한다. 이름·생년월일·CI·DI·PG 원문은 DB·로그에 저장하지 않는다. 요청 기록은 만료 후 1일 지난 항목을 다음 요청 시 정리한다.

## 아직 활성화하지 않은 이유

승인·다날 채널·키가 없으므로 운영에서는 결제/본인확인 `enabled:false`다. 설정 없는 상태에서 주문 생성, 결제 완료, 성인 확인을 위조하지 않는다. 고객 화면에도 준비 중으로 표시한다. 자동 테스트는 임시 SQLite와 공급자 응답 모의값을 사용했고 실카드 결제·다날 실제 인증은 하지 않았다. 본인확인 연동 자체가 성인 전용 콘텐츠 제공·심사 완료를 의미하지 않는다.

## 발급 후 설정 (값은 서버 보호 env에만)

```dotenv
PORTONE_MODE=live
PORTONE_APPROVED_ORIGIN=https://azitchat.com
PORTONE_PAYMENT_ENABLED=false
PORTONE_V1_USER_CODE=
PORTONE_PAYMENT_CHANNEL_KEY=
PORTONE_DANAL_PG_ID=
PORTONE_V1_API_KEY=
PORTONE_V1_API_SECRET=
PORTONE_IDENTITY_ENABLED=false
PORTONE_STORE_ID=
PORTONE_IDENTITY_CHANNEL_KEY=
PORTONE_V2_API_SECRET=
```

1. 아지트챗 URL·상품에 대해 승인된 다날 MID/채널인지 확인한다. 기존 비즈사주 MID를 사용하지 않는다.
2. 다날 본인확인의 **전화번호 제공 계약 옵션**을 확보한다. 반환 번호가 없으면 다른 번호 계정에 신원을 붙이지 않도록 검증이 실패한다.
3. 실제 제공 업체·처리 항목·보관·동의 등 확정된 계약에 맞춰 개인정보처리방침과 인증 화면을 갱신·고지한 뒤 활성화한다. 현재 정책은 운영 전 안내를 유지한다.
4. 승인된 테스트 채널과 임시 계정에서 PG 결제창·인증창 실제 실행, PC/모바일 복귀, 본인 명의 전화번호, 성인/미성년 구분을 확인한다. 가짜 인증 성공을 만들지 않는다.
5. 실운영 전 승인된 LIVE 채널의 소액 결제·취소는 소유자가 직접 수행한다. 결제창 성공/서버 지급/새로고침/웹훅 중복/지급 원장/취소 복구를 확인한다.
6. 환경별 webhook URL은 `/api/payment/webhook`. 결제 요청의 `notice_url`로 아지트챗 전용 URL을 지정한다. 기존 비즈사주 전역 webhook 설정은 변경하지 않는다.
7. 확인이 끝나면 해당 기능의 ENABLED만 true로 바꾸고 서비스 재시작 후 `/api/payment/config`, `/api/identity/config`와 운영 상태를 확인한다. 활성화 이후 상품·정책·소개 페이지의 ‘준비 중’ 문구도 실제 제공 상태로 변경한다.

## 일반 이용과 성인 제한 콘텐츠 (2026-10-19)
- 서비스 전체는 성인 전용이 아니다. 일반 대화는 성인인증 없이 가능하고, 문자 번호 인증은 성인인증이 아니다.
- 콘텐츠 접근은 서버에 저장된 본인확인 결과(verified/isAdult/verifiedAt)와 연결 전화번호로만 판단한다. 클라이언트의 나이·인증 주장과 관리자 비밀번호는 근거가 아니다.
- 실제 대화 입력과 AI 출력에 문맥 기반 안전 분류를 적용한다. 미인증·미성년자는 성적인 대화를 차단하며, 첫 인사·선물·먼저 연락·관리자 미리보기에도 출력 검사가 적용된다. 미리보기는 기본 일반 모드다.
- 차단·분류 장애 시 AI 답변·기억·하트 차감이 커밋되지 않는다. 인증 안내는 캐릭터 발화가 아닌 중앙 공지와 인증 상태 확인 링크로 표시한다.
- 성인인증 후에도 노골적인 성적 묘사와 미성년자 성적 대상화는 제공하지 않는다. 생성 API의 성적 안전 필터를 활성화한다.
- 현재 정식 인증 연동이 비활성 상태이므로 이용자는 일반 대화만 이용한다. 성인 전용 콘텐츠에 대한 심사·계약 승인을 의미하지 않는다.

## 정책 보강 2.0 (2026-10-19.2)
- AI 대화·매칭·신규 구매/본인확인 준비에는 최신 약관 동의와 개인정보/AI 안내 확인 및 만18세 이상 자기 확인이 필요하다. 서버는 기본 미동의로 처리한다. 이를 보호자 동의나 만19세 성인인증으로 취급하지 않는다.
- `/api/legal/status`, `/accept`, `/stop` 및 `legal_acceptance_events`로 버전·시각·수락/중단을 기록한다. 번호 계정 전환 시 기록을 유지하고 클라이언트 상태 저장으로 동의를 위조하지 못한다.
- Gemini 계약상 만18세 미만 이용자에게 서비스 제공하지 않는다. 본인확인으로 18세 미만이 확인되면 자기 확인이 있어도 차단한다. `isAtLeast18`은 검증된 결과에서만 저장한다.
- 공개 문서는 `/policies`, `/safety`, 보강 전 약관/방침/환불 보관본을 포함한다. 기존 고객에게 동의 이력을 소급 생성하지 않는다.
- 접속 로그에서 쿼리·리퍼러를 제외하고 30일 일별 회전 설정을 설치한다. 분석 쿠키는 최대180일·미갱신으로 제한하며 철회 시 브라우저 쿠키를 지운다.

## 토스 반려 보완 (2026-10-20)
- 신규 하트 상품은 지급·구매일부터 최대 1년. 이미 저장된 기존 지급분의 만료일은 수정하지 않는다. 실결제 준비 중이므로 신규 판매 조건을 1년으로 일치시킨다.
- 심사서의 ‘서비스 제공 완료 기간’은 하트 충전 처리시간만을 뜻한다고 가정하지 말고 최종 이용기간을 포함해 최대12개월 이내로 기재한다.
- 약관·보호정책·인증 안내에19세 미만/미인증자 모니터링·성인 기능 차단을 명시. 관리자 수동 인증은 실제 기관 인증으로 대체할 수 없다.
- `/billing#identity`는 로그인용 문자 인증과 별개의 성인인증 진입 단계다. 계약 미개통 시 준비 중임을 표시하며 인증기관 창처럼 꾸미지 않는다.
- 다날 계약 완료 및 실제 LIVE 채널 구성 후 인증기관 창을 열어 URL/서비스 출처가 확인되는 실제 스크린샷을 확보한다. 토스 기타 서류에 첨부하고 재접수한다. 지금은 다날 계약 진행 중이므로 해당 증빙 미비 상태에서 재제출하지 않는다.
