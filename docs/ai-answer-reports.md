# AI 답변 신고 운영 · 2026-10-22

사용자 간 교류 신고가 아니라 AI가 생성한 답변의 안전·품질 문제를 다룬다.

- 대화의 AI 답변 아래 `답변 신고` → 사유 및 선택 설명 → 접수. 회원·게스트 모두 가능하다. 분할 말풍선도 하나의 서버 답변으로 중복 접수를 방지한다.
- 신고 시 해당 답변 및 앞선 최대 4개·뒤의 최대 2개 메시지만 보관한다. 서버가 소유 계정과 AI 발화를 확인하며 클라이언트가 제출한 원문을 신뢰하지 않는다. R2 보관 대화도 기존 복원 경로를 사용한다.
- 홈 하단 `내 AI 답변 신고` 또는 대화 하단 `신고 내역`에서 상태와 공개 결과를 확인한다. 게스트는 동일 브라우저에서, 번호 연결 후에는 연결 계정에서 확인한다. 내부 메모·검토 이력은 신고자에게 노출하지 않는다.
- 관리자 `AI 답변 신고` → 접수 목록 → 검토·조치. `검토 시작`, `검토 메모`, `문제 없음`, `개선 조치 기록`, `캐릭터 제공 일시 중지/재개`를 제공한다. 근거는 필수이고 종결·중지·재개에는 신고자 안내도 필수다. 동시 수정은 버전 충돌로 막는다.
- `개선 조치 기록`은 실제 설정/정책/코드 등을 수정한 뒤 근거를 남기는 기능이다. 이 메뉴만으로 프롬프트·기존 답변이 자동 수정되지는 않는다. 필요한 설정 수정은 캐릭터 스튜디오에서 별도 검토·게시한다.
- 제공 중지는 신규 소개, 첫 인사, 기존 방의 새 답변·선물 반응·선연락을 서버에서 차단한다. 생성 중 조치에도 저장·하트 차감 전에 다시 확인한다. 기존 대화 원문을 삭제하거나 신고자를 제재하지 않는다. 재개 시 동일한 차단을 해제하며 기존 스튜디오 비공개 설정은 해제하지 않는다.
- 신고와 제한 맥락 및 처리 이력은 접수 후 365일을 넘으면 삭제한다(시간별 정리). 원문 만료 후에도 제공 중지는 자동 해제하지 않으며, 관리자 중지 목록에서 검토 근거를 남기고 재개할 수 있다. 감사 기록에는 신고 원문을 복제하지 않는다.
- 실제 신고 수신을 24시간 상시 인력이 감시하거나 정해진 시간 내 처리한다고 보장하지 않는다. 문의·이의는 기존 고객센터로 받는다. 신고는 자동 환불을 의미하지 않는다.

검증: `node server/tests/ai-reports.cjs`는 소유권·게스트·분할 중복·제한 맥락·관리자 인증/CSRF·비공개 메모·공개 결과·동시 수정·실제 제공 중지/재개·생성 도중 차단 시 무차감·원문 보관 만료·계정 이전을 확인한다. 로컬 모바일 UI에서 접수 및 관리자 검토 저장을 확인했다.
